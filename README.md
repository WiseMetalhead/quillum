# Quillum

**Персональное пространство для ваших фантазий**

[![Version](https://img.shields.io/github/v/release/WiseMetalhead/quillum?label=version&style=for-the-badge&color=F5641E)](https://github.com/WiseMetalhead/quillum/releases)
[![License: AGPL v3+](https://img.shields.io/badge/license-AGPL%20v3%2B-BB181E.svg?style=for-the-badge)](LICENSE)
[![Docker](https://img.shields.io/badge/docker-GHCR-B45309.svg?style=for-the-badge&logo=docker&logoColor=white)](https://github.com/WiseMetalhead/quillum/pkgs/container/quillum)

Платформа для авторов, объединяющая в себе удобное пространство для планирования творческого процесса и создания художественных произведений, как небольших историй и рассказов, так и полноценных романов.

Проект в первую очередь ориентирован на русскоязычное сообщество, но большая часть основных функций не привязана к региону. В том числе присутствует английская локализация.

## Возможности

- **Рукописи, как проекты** — создавайте короткие произведения, романы или серии романов и организовывайте отдельные пространства для работы с ними.
- **Планирование** — ставьте цели, устанавливайте дедлайны и организовывайте списки задач.
- **Заметки** — не держите в голове! Фиксируйте идеи к рукописи или записывайте мысли на будущее, как текстом, так и голосом.
- **Глоссарий** — сложная вселенная и её структура, как на ладони. Творите миры и держите всю информацию о них в одном месте.
- **Редактор текста** — работайте над книгой в удобном редакторе и фокусируйтесь на процессе, когда это нужно.
- **Черновики и редакции** — возвращайтесь к прежним версиям текста и создавайте контрольные точки процесса.
- **Совместная работа** — делитесь текстами со знакомыми или подключайте редакторов для совместного редактирования в реальном времени.
- **Статистика** — отслеживайте процесс работы и следите за вашими успехами.
- **Уведомления** — всё самое важное не останется без вашего внимания.

... и многое другое!


## Быстрый запуск с автоматическим HTTPS

Требуются Linux-сервер, Docker Engine с Compose v2, публичный домен и открытые порты 80/443.
Официальный образ первого публичного релиза поддерживает `linux/amd64`.

```bash
git clone https://github.com/WiseMetalhead/quillum.git
cd quillum
./scripts/public/init.sh
```

Отредактируйте `.env.production`, заменив `write.example.org` своим доменом, затем запустите:

```bash
./scripts/public/up.sh
./scripts/public/status.sh
```

Первичный пароль администратора хранится только в локальном файле
`.secrets/bootstrap_admin_password`. После первого входа немедленно смените его в настройках
безопасности.

Для сервера с уже настроенным reverse proxy:

```bash
./scripts/public/up.sh --external-proxy
```

Gateway будет доступен только на `127.0.0.1:8080`. Пример обязательных proxy-настроек приведён в
[руководстве по развёртыванию](docs/public/deployment.md).

Локальная сборка вместо загрузки GHCR-образа:

```bash
./scripts/public/up.sh --build
```

Транскрибация Whisper загружается отдельно и требует около 3 ГиБ доступной памяти:

```bash
./scripts/public/up.sh --transcription
```

## Обновление и резервные копии

Перед обновлением обязательно создайте offline-копию:

```bash
./scripts/public/backup.sh
```

Измените `QUILLUM_IMAGE` на новый точный тег, выполните `docker compose pull`, затем снова вызовите
`./scripts/public/up.sh`. Не используйте плавающий `latest` для установок с ценными данными.

Полная процедура восстановления описана в
[руководстве по резервному копированию](docs/public/backup-and-restore.md).
