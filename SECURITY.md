# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной minor-линии `1.x`. После выхода
новой minor-версии предыдущая получает исправления только при отдельном объявлении.

## Сообщение об уязвимости

Не создавайте публичный issue с деталями уязвимости. Используйте **Security → Report a
vulnerability** в репозитории `WiseMetalhead/quillum`. Проект использует GitHub private vulnerability
reporting и не публикует отдельный email для security-отчётов.

Укажите затронутую версию, способ воспроизведения, влияние и предлагаемые меры. Не проверяйте
уязвимость на чужих установках и не извлекайте чужие данные.

## Граница ответственности

Quillum хранит прикладные данные как plaintext. Оператор отвечает за HTTPS, доступ к серверу,
шифрование дисков и резервных копий, обновления ОС и контейнеров, а также сохранность secret-файлов.
