### Добавлено

- В Product Admin добавлено управление OpenID Connect для самостоятельных Compose-установок.
  Значения из окружения и secret-файлов сохраняют приоритет и остаются недоступными для
  изменения через интерфейс.
- В сведениях о приложении Product Admin теперь отображается чейнджлог установленной версии.
- В настройках пользователя, Ленте, Рукописях, Сериях и списке доступных редактору рукописей
  добавлены сворачиваемые боковые панели.

### Изменено

- Обновлён фирменный знак Quillum, включая favicon, Apple Touch Icon и PWA-иконки; переработано оформление
  README.
- Настройки Product Admin получили выровненные столбцы, компактные действия и стабильную высоту строк при
  редактировании.
- Лимиты запросов в Product Admin теперь редактируются через локализованный структурированный контрол с
  отдельными значениями лимита, периода и единицы времени.
- Для изменения обычных runtime-настроек, проверки SMTP, квот уровней и автоматического повышения уровня
  больше не требуется повторная аутентификация. Защита сохранена для ролей пользователей, уведомлений,
  служебных страниц и других чувствительных операций.
- «Журнал аудита» переименован в «Журнал событий»; добавлены локализованные названия событий раздела «Идеи».
- Унифицированы кнопки в пользовательских настройках, а поле поиска в шапке теперь плавно расширяется при
  получении фокуса.

### Исправлено

- Длинная версия PostgreSQL больше не перекрывает статус сервиса в Product Admin.
- Исправлены расположение и разделители элементов проверки уведомлений, выравнивание значений и статусов
  настроек, а также изменение высоты строк при переходе в режим редактирования.
- Раздел «Аккаунт» теперь занимает освободившееся пространство после сворачивания сайдбара.
- Разделитель между «Сериями» и «Ящиком» корректно растягивается внутри свёрнутого сайдбара Рукописей.

### Техническое

- Обновлены uv до 0.13.8, Ruff до 0.17.5 и закреплённые образы Redis.
