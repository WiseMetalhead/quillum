### Добавлено

- На компьютерах и планшетах поиск в шапке учитывает текущий раздел в Рукописях, открытой Серии, Досках и Глоссарии. Сначала показываются совпадения в разделе, затем результаты по рабочему пространству без повторов. Активный фильтр виден в панели инструментов и сбрасывается одним нажатием.

### Изменено

- В Планировщике, Досках и Глоссарии появились сворачиваемые боковые панели. Выбранное состояние сохраняется в браузере и применяется во всех поддерживаемых разделах.
- Свёрнутую панель можно временно раскрыть наведением мыши или клавиатурным фокусом.

### Исправлено

- PyAV обновлён до 18.1.1. В этой версии исправлена ошибка с повреждением памяти при декодировании аудио, из-за которой была отозвана версия 18.1.0.

### Техническое

- Tiptap обновлён до 3.35.0. Браузерный редактор, общая схема документа и сервер совместного редактирования используют одну версию ядра Tiptap и его пакета ProseMirror.
- Обновлены React и React DOM до 19.3.1, Vite до 8.3.8, i18next до 26.7.2, React i18next до 17.1.13 и Redis-клиент сервиса совместного редактирования до 5.12.4. Также обновлены Noto Sans, наборы иконок и инструменты проверки frontend-кода.
- Обновлены Authlib до 1.9.10 с исправлениями безопасности, PyOTP до 2.12.1, NumPy до 2.5.5 и набор корневых сертификатов certifi до 2026.11.20.
- В публичной Docker-сборке uv обновлён до 0.13.9. Обновлены закреплённый образ Caddy для Compose и Ruff до 0.17.6.
- GitHub Dependency Review обновлён до 5.0.1. В перечень разрешённых лицензий добавлена CC0-1.0, которую NumPy указывает для компонента SplitMix64.
